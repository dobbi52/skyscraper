# 스카이스크래퍼

1층부터 5층까지 건물을 세우는 높이 단서 논리 퍼즐이에요. 바깥 숫자는 그쪽에서 보이는 건물 수예요.

- 게임 주소: https://dobbi52.github.io/skyscraper/
- 로그인: 생각 오락실 통합 계정 (https://dobbi52.github.io/games/)
- 기록 저장: `server/Code.gs` (Google Apps Script 웹 앱 + 구글 시트 '기록')

## 구성

- 오늘의 퍼즐: 쉬움·보통·어려움, 학생(계정)마다 다른 판이 날짜별로 정해져요. 하트 3개, 힌트 3번.
- 연습: 쉬움·보통·어려움 무제한, 힌트 5·4·3번, 틀린 숫자 바로 표시.
- 보상: 오늘의 퍼즐 별 → 건물 10채, 연습 벽돌(하루 5개) → 꾸미기 7개, 연습 판 수 → 특별 장식 5개.
- 힌트: 지금 판에서 기본 규칙으로 알 수 있는 칸과 그 이유를 설명해요.

## 설정 바꾸기 (index.html)

- `CONFIG` — 하트·힌트 개수, 단계별 별, 건물이 생기는 별 기준(`BUILDING_AT`), 연습 벽돌 하루 상한
- `LEVEL_RULES` — 단계별 미리 채우는 칸 수와 남기는 단서 수
- `SAVE_API` — 기록 저장 서버 주소

## 서버 설치

1. 새 구글 스프레드시트를 만들어요.
2. 확장 프로그램 → Apps Script → `server/Code.gs` 내용을 붙여 넣고 저장해요.
3. 배포 → 새 배포 → 웹 앱 (실행: 나 / 액세스 권한: 모든 사용자) → 배포.
4. 나온 웹 앱 주소(…/exec)를 `index.html`의 `SAVE_API`에 넣어요.
